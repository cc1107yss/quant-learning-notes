# Quant Learning Notes

Concise English notes on quantitative finance, trading, and related topics.

## Goals

- Capture the key ideas from learning.
- Explain concepts clearly and briefly.
- Keep useful formulas, examples, and references easy to review.

## Organization

Notes are grouped by topic and written in English. Each note focuses on the main takeaway, essential details, and practical intuition.

## Note Format

Where useful, notes may include:

- **Summary** — the core idea in a few sentences.
- **Key points** — the concepts worth remembering.
- **Formula or example** — a compact technical reference.
- **Takeaway** — how the idea can be applied.

This repository is a learning record and is not financial advice.
