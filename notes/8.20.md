# 波动率
“价格波动幅度”

年化波动率：市场估计价格未来一年可能有的波动
## 历史波动率 Historical Volatility，HV
通常步骤是：
1. 计算每日收益率
2. 计算收益率的标准差
3. 年化处理
   
简化公式：
HV = 每日收益率标准差 × √252

它回答的是：
过去这段时间，价格实际波动了多少？
## 隐含波动率 Implied Volatility，IV
期权价格通常受到以下因素影响：
- 标的价格
- 行权价
- 到期时间
- 无风险利率
- 股息
- 波动率
## 一些概念
Call：获得按行权价买入的权利。

Put：获得按行权价卖出的权利。

标的价格等于行权价时，叫 平价 ATM（At the Money）。

价内不等于一定赚钱，因为还要扣除权利金。

买 Call：获得按固定价格买入的权利

卖 Call：收钱，并承担按固定价格卖出的义务

买 Put：获得按固定价格卖出的权利

卖 Put：收钱，并承担按固定价格买入的义务

| 概念 | 定义 | Long Call 例子 |
|---|---|---|
| 标的价格 | 期权对应资产当前的市场价格，例如股票、ETF 的价格 | ETF 当前价格 $100 |
| 行权价 Strike | 期权合约约定的买入或卖出价格 | Strike = $105 |
| 到期日 Expiry | 期权合约失效、最终结算的日期 | 2026-12-31 到期 |
| 权利金 Premium | 买方购买期权支付给卖方的价格；也是卖方收到的钱 | 每股 $3，一张合约通常是 $300 |
| 到期 Payoff | 期权到期时本身产生的价值，尚未扣除权利金 | Call payoff = `max(到期价格 - 105, 0)` |
| 实际 P&L | 真正的盈利或亏损，通常等于 Payoff 减去权利金及交易成本 | 到期价格 $120：Payoff $15，P&L = $15 - $3 = $12/股 |
| 价内 ITM | 如果现在执行期权，期权具有正的内在价值 | Call：标的价格 > Strike；Put：标的价格 < Strike |
| 价外 OTM | 如果现在执行期权没有经济意义，期权内在价值为 0 | Call：标的价格 < Strike；Put：标的价格 > Strike |
| 盈亏平衡点 | 到期时刚好不赚不亏的标的价格 | Long Call：`Strike + Premium` = $108 |
